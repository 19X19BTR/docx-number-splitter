# Word 文档按序号拆分

一个 200 段的 Word 素材，内容是 `1.` `2.` `3.` 编号的独立条目，要拆成 200 个 docx 文件发出去。手动复制粘贴不现实，就写了这个。

## 特点

- **切口就是行首序号**：`1.` `2.` `31.` 都是切口，不管点后面有没有空格（`1.正文` 也能切）
- **中文全角句点也认**：`1．正文`
- **不误杀正文**：只在**行首**出现 `数字+点` 时才切，正文中间的 `31.` 不会被当成新条目
- **文件名可控**：`--prefix 题目_` → `题目_1.docx`，不写就是 `1.docx`
- **macOS / Windows 都有文件选择框**，不会用命令行也能跑

## 安装

```bash
pip install -r requirements.txt
```

## 用法

交互式（弹窗选文件）：

```bash
python split_doc.py
```

命令行：

```bash
python split_doc.py --input 素材.docx --outdir ./split_result --prefix 题目_
```

```
全部拆完！共 187 个文件 → /Users/me/Desktop/split_result
```

| 参数 | 说明 |
|---|---|
| `--input` | 要拆的 `.docx`，不给就弹窗选 |
| `--outdir` | 输出目录，默认源文件旁边的 `split_result/` |
| `--prefix` | 文件名前缀，留空用纯序号 |

## 拆分规则

```text
输入：
1.第一题内容……
2. 第二题内容……
正文里提到了 31. 这个数字，但不在行首，不会被切
3．第三题（全角句点）

输出：
1.docx  → "1.第一题内容……"
2.docx  → "2.第二题内容……正文里提到了 31. 这个数字，但不在行首，不会被切"
3.docx  → "3.第三题（全角句点）"
```

正则核心就一行：

```python
re.compile(r'(?:^|\n)(\d{1,3})(?:[.\uff0e])(.*?)(?=\n\d{1,3}[.\uff0e]|$)', re.S)
```

## 已知限制

- 只处理**段落文本**，表格里的内容、图片、页眉页脚不会带走
- 序号必须是行首的 1–3 位阿拉伯数字，`（1）` `一、` 这类不认
- 拆出来的每个文件是纯段落，不带原文档的样式和标题层级
